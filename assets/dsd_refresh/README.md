# 九百九十九夜刷新按钮模板

来源：用户在本次修复中提供的 2560×1440 游戏截图。仅保留左上角按钮内部的牛头和冷却数字，不含账号、背景或整张截图。

- `ready.png`：没有冷却数字的牛头图标。
- `cooldown.png`：刷新后显示 `60s` 的图标。其他数字不保证匹配，识别不确定时退出等待。

区域为屏幕比例 `(0.042, 0.199, 0.074, 0.245)`。匹配时归一化到 96×96，排除按钮边框和悬停高亮。仅用于此任务的 OCR 兜底，不注册为全局 Labels。

适用于默认 UI、16:9。1080p、1440p、2160p 用缩放样本验证；真实游戏目前仅有 1440p 样本，其他分辨率仍需实测。
