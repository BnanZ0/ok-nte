# 消耗体力培养角色（模块版本 1.5.8.7）

按「养成指南」里当前培养目标的材料缺口，自动消耗体力刷取材料。作为**独立功能**出现在任务列表，与「异象界域 / 异象追猎 / 异象巡礼」同级，互不干扰。模块版本号独立于 ok-nte 宿主版本；合入宿主发布前，可用性以插件版发布为准。

## 它做什么

任务开始时打开角色的养成指南页，一次读全四行目标材料的拥有/需求数字（账本模式），然后按缺口自动选本、刷体力：

1. 读取当前体力与四行材料 `拥有/需要`，识别出每行材料属于哪个副本。
2. 按固定优先级逐行补齐，**周本（异象巡礼）> 等级第2行（世界BOSS）> 异能第1行 > 弧盘第2行**。
3. 连打全自动：只要当前副本产出还不足以覆盖缺口就一直「继续挑战」，缺口刷够自动换下一个副本。
4. 每局领奖后在日志输出掉落统计：各材料本次掉了多少、已有多少、还差多少。
5. 某一行刷满自动换下一行；四行全满后切到「空幕」把剩余体力花完；体力不够下一次时停止。

### 材料行与副本映射

| 培养目标行 | 产物来源 | 单次体力 | 备注 |
|---|---|---|---|
| 异能 第2行 | 异象巡礼（周本） | 60 | 每周 3 次；第2行是周本材料，不是世界BOSS |
| 等级 第2行 | 异象追猎（世界BOSS） | 60 | 野外 BOSS，传送后走到跟前再打 |
| 异能 第1行 | 异象界域副本 | 40 | 可双倍领取、可连打 |
| 弧盘 第2行 | 弧盘副本（泡影罐头） | 40 | 第1行是通用升级材料，非副本产物，不刷 |

其它行（小怪掉落、经验卡、等级第1行等）不在本功能范围内。

## 安装方式

**方式一：随宿主安装**（合并 PR 后的正式版）：更新 ok-nte 后任务列表自带本功能。

**方式二：插件安装**（推荐，不随宿主更新被覆盖）：

1. 打开 ok-nte 的「插件」页 → **Add from GitHub** → 输入 `Camellune/ok-nte-cultivation-goal`，从 Release 选择最新 `.okscript` 安装。
2. 也可从 https://github.com/Camellune/ok-nte-cultivation-goal/releases 下载插件包后，从本地文件安装。
3. 安装后任务列表出现「消耗体力培养角色」，随插件独立更新，宿主升级不影响它。

两种方式不要同时启用，功能重复注册会互相干扰。

## 怎么用

1. 游戏分辨率设为 **1920x1080 / 16:9**，语言为**简体中文**（导航与页面识别只匹配中文文案，其他语言界面暂不支持）。
2. 在游戏里先打开角色详情页，选好要培养的角色（本功能读取的是该角色的养成指南目标）。
3. 在 ok-nte 任务列表找到 **「消耗体力培养角色」**，点开配置后启动。

## 配置项

| 配置 | 默认 | 说明 |
|---|---|---|
| 目标消耗体力 | 180 | 今日累计体力花到这个数就停；设 0 表示不受每日目标限制，按缺口刷到材料齐全——齐全后仍会切空幕继续消耗剩余体力。**启动时今日目标已达成也按「不限额」处理**：任务会继续消耗当前体力，剩余体力不会留着 |
| 周本刷取 | 开 | 周本刷取开关：开=优先刷满本周 3 次周本再刷其它材料；关=直接刷其它材料，周本只在异能第2行缺料时才打 |
| 掉落统计 | 开 | 每局领奖后在日志统计各材料本次掉落多少、已有多少、还差多少 |

连打为自动判定，无配置项：按上一局产出估算缺口，产出足够覆盖需求即换下一个副本，否则一直连打（内部保险丝上限 20 局）。

## 双倍体力

- 副本（异能/弧盘）和异象界域副本支持「双倍领取」：一次耗两份体力、领两份奖励，收益与打两局相同但只打一场。
- 当这一行缺口 ≥ 2 份且体力够两份时自动走双倍；缺口只剩 1 份或体力不足时退回单倍，避免溢出浪费。

## 识别与掉落统计

- 材料行数字用 OCR 读取；斜杠偶发被认成 `1`（如 `47/60`→`47160`），解析层会自动修复，失败时分级重试（原样→二值化→灰度）。
- 材料图标、奖励清单掉落均由本地模板库识别，不读取游戏内存、不修改游戏文件。
- 掉落按每局领奖清单本地累计入账（账本模式），掉落读不出时自动回养成指南复核一次，不凭空猜数。
- 每次运行另存一份 JSONL 证据链到 `logs/cultivation_goal.jsonl`，可用 `python -m src.tasks.cultivation_goal.report` 查看，便于离线复盘与排查假成功。

## 注意事项 / 故障排查

- **读不出材料行**：确认处于目标角色的养成指南页、分辨率 1920x1080；读空且没有上一轮读数时才自动截图到 `screenshots/`（沿用上一轮数值的行会标 stale，不重复截图），可据图判断是坐标偏差还是页面未打开。
- **连续跳行**：若某行连打 2 局零产出，本场会跳过该行继续其它行，避免卡在一处烧体力；多为落点或坐标偏差。
- **周本跑不完**：异象巡礼中途失败（如传送按钮无响应）时，本场不再尝试周本，已领到的次数照常计入。
- **本功能不覆盖**：小怪/经验卡/等级第1行等产物；这些行不在四行目标内。
- 运行逻辑与三个异象功能相互独立，关闭本功能后它们仍按原版行为执行。
