# 功能概览

- **后台运行**：支持 PC 游戏在后台运行时进行自动化操作。

### 📅 日常/周常

自动完成所选日常/周常任务。

- **一键日常**：按配置自动执行任务流程。
- **可选任务**：经验与甲硬币、异能升级材料、弧盘突破材料、空幕、一咖舍、影院约会、羁遇赠礼、异象家具、异象追猎、喷泉签到、商店购买。

### 🍹 都市闲趣
- **自动钓鱼**：全自动钓鱼。
- **自动鼓组音游**：自动完成鼓组音游。
- **店长特供**：自动循环进出关卡（需配合游戏内挂机流派使用）。
- **自动粉爪大劫案**：自动完成粉爪大劫案（一小时方斯410000+ / 粉爪币2500+）。
- **粉爪大劫案便利性功能**
    - **快速拾取**：快速拾取关卡内道具。
    - **自动切换角色快速奔跑**：自动切换角色以保持快速奔跑。

### 📋 特定挂机与副本 (任务)
- **九百九十九夜**：挂机刷经验。
- **异象界域**：自动化挑战异象界域。

    - **刷取策略**: 固定目标选择类别和序号; 同类轮换只选择类别; 自定义轮换添加材料并调整队列顺序。默认仍为固定目标。
    - **体力使用**: 「用完当前体力」会重新读取剩余体力, 不受每日完成状态影响, 不自动使用体力药。「消耗指定体力」以本次上限为准, 不会向上超支。日常入口另有「完成每日」, 保留原有每日体力和活跃度判断。
    - **进阶设置**: 默认每项额度为一次双倍奖励的体力, 普通副本 `80`, 空幕 `120`。可修改每项最低体力, 按单份消耗 `40`/`60` 向上取整; 也可按队列顺序填写英文逗号分隔的不同额度。允许时优先双倍, 额度或体力只够一份时领取单倍。领取奖励次数按份数计算, 双倍算两份。
    - **续刷与统计**: 每次确认结算后保存轮换进度、各目标单倍/双倍次数和消耗体力; 明细保存在 `stats/anomaly_claims.csv`。这些是领奖统计, 不代表实际材料掉落数量。下次从未完成额度继续; 改变队列或额度会重建进度, 也可开启「下次运行重置轮换」从首项开始。
    - 剩余体力或本次额度不足当前目标的一份奖励时停止并保留顺序, 不跳过该目标。日常的旧「循环模式」保留在固定目标的进阶设置中, 仍在本次日常成功后更新下次目标。

- **异象追猎**：自动化挑战异象追猎。
- **自动小旋风**：自动完成「小旋风」战斗。
- **排球之星**：支持刷经验、自动闯关和自动周赛。
- **噗卡乐园 - 命中幸运星**：自动完成飞镖小游戏，循环刷星票。
- **呗果智能体**：在呗果社区中自动发帖、回帖、点赞，或开启助手模式辅助生成文案。

### ⚡ 常驻触发与战斗 (实时触发/角色中心)
- **自动战斗**：基于计算机视觉的战斗算法，由 **角色中心** 提供自定义出招表与特征管理支持。
- **角色中心**：为 **自动战斗** 提供支持。
    - **角色管理**：支持自定义出招表，灵活配置战斗逻辑。
    - **特征管理**：适配不同角色皮肤，支持自动识别并切换对应的战斗逻辑。
    - **出招表**：支持文本型出招表，以及内置或外置的代码型出招表。
    - **工坊**：下载并使用社区分享的出招表方案。
- **声音驱动**：基于音频反馈实现的自动闪避和反击。
- **跳过对话**：跳过冗长的剧情对话。
- **快速传送**：自动点击地图传送。

### 🎹 独立娱乐与辅助
- **自动弹琴**：自动分析 MIDI 音轨并完成钢琴演奏。
